02 / PREMIERS PAS

Du téléchargement à la partie.

  1. 01

    Choisissez Windows

    Téléchargez le paquet Windows lorsqu’il est disponible. Le lien pointe vers les fichiers du jeu, pas vers l’archive du code source.

  2. 02

    Préparez le dossier

    Pour une version ZIP, choisissez « Extraire tout » et conservez tous les fichiers ensemble. Pour un installateur, suivez ses étapes.

  3. 03

    Suivez le guide du jeu

    Ouvrez les instructions fournies dans le téléchargement pour connaître le lanceur et les éventuels prérequis de cette version.
