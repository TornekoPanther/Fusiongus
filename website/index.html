02 / PRÉREQUIS ET INSTALLATION

Préparez vos données Fusiongus.

Ce paquet nécessite une extraction privée de Fusiongus-portable-2026-11-01-campagnes.zip contenant PORTABLE-MANIFEST.json et prototype/data. Une installation Wargus standard et l’import depuis d’autres mods ne sont pas pris en charge. Sans cette source compatible, le téléchargement seul ne permet pas de jouer.

  1. 01

    Extrayez dans un dossier neuf

    Choisissez « Extraire tout » pour le paquet moteur + mod. Conservez votre extraction privée compatible et vos sauvegardes dans leur dossier d’origine.

  2. 02

    Importez vos données

    Lancez Configurer Fusiongus.cmd, puis sélectionnez le dossier Fusiongus de l’extraction privée compatible. L’import copie et vérifie environ 700 Mo de données dans work-data, sans reprendre les profils et sauvegardes d’origine.

  3. 03

    Vérifiez, puis lancez

    Utilisez Verifier les donnees.cmd pour vérifier l’import, puis Lancer Fusiongus.cmd pour démarrer avec un profil neuf. Le guide inclus dans le ZIP détaille aussi la configuration en ligne de commande.

Pour partager le paquet public, utilisez uniquement le ZIP d’origine. Le dossier configuré contient vos données importées et ne doit pas être republié.
